# v0.2.8 병사 가독성 및 한국어 전술 검사 감사

기준은 v0.2.7이 병합된 main `f94d0ed`이다. 작업 브랜치는 `feat/v028-soldier-readability`이며 자동 병합하지 않는다. 이번 변경은 표시 계층에 한정한다. 기존 simulation, intelligence, tactics, coordination, search, world, grenades, medical/mounting 및 combat-visuals 모듈은 기준과 바이트 단위로 동일하다.

## 구현 및 권위 있는 데이터

- 기존 절차적 인간형 애니메이션을 유지하고 `readability.js`에서 읽기 전용 보조 표시를 추가했다. 실제 이동 시 발밑 이동선, 별도의 관측 방향선, 완전 엄폐·피킹·거치·재장전·치료·투척 준비·제압 상태의 색상 고리, 실제 부상 표시, 전투 불능/사망 구분을 표시한다. 진영별 원래 군복 색상은 보존한다.
- 관측선은 `observationHeading`, 이동선은 `movementHeading`과 `presentation.moving`을 읽는다. 무기 방향·실제 발사·반동·보행/달리기·치료·수류탄 투척·쓰러짐은 기존 `CombatVisuals`가 실제 상태/이벤트로 계속 제어한다. 새 고리는 총탄이나 방호 계산을 바꾸지 않는다. 지속 사격 자세는 실제 사격 중이라는 보장이 아니다.
- `korean-inspector.js`는 실제 상태, 명시적 `decisionReason`, 엄폐 자세/근거, 임무/역할/이동 목표, 부위별 실제 건강, 탄약/재장전, 제압, 진단 접촉 출처와 경과 시간, 직접 시야와 사격 허용, 관측/이동 방향, 치료 대상과 1초 치료 주기 진행, 거치, 제압사격, 항법/횡단, 기존 중복 없는 활동 시간을 읽는다. 치료 백분율은 전체 부상 회복률이 아니다.
- 적의 실제 객체나 원시 기억 좌표를 검사 화면에서 조회하지 않는다. 접촉 표시는 기존 지식 한정 `diagnostics`에서만 가져온다. 표시되는 이동 목표는 자신의 배정 목적지이며 적의 현재 위치라는 주장이 아니다. 누락된 판단 근거는 `판단 근거 기록 없음`으로 표시한다.

## 한국어 및 판단 기록

플레이어용 상태·역할·자세·사격 사유·항법·관측·역할 근거를 명시적 사전으로 번역한다. 소스에서 직접 대입되는 101개 상태/사유 리터럴은 모두 지원한다. 기존 v0.2.7 문제 재현 기록에서 확인한 주요 조건부 사유도 추가했다. 내부 식별자나 전투 로직은 번역하지 않는다. 미래의 새 문자열이나 일부 동적 설명은 안전한 한국어 대체 문구로 표시되므로 모든 가능한 런타임 문자열의 번역 완전성을 주장하지 않는다.

판단 이력은 병사별 WeakMap에 최대 18개를 보관한다. 행동·자세·임무·명시적 판단·제압사격 사유의 실제 관측된 변경 및 확인 접촉 갱신을 기록한다. 같은 값은 반복하지 않으며 접촉 갱신도 모아 표시한다. 화면은 10Hz로 갱신한다. 따라서 4×에서 표본 사이에 생겼다가 사라진 짧은 전환은 빠질 수 있다. 이력은 완전한 시뮬레이션 이벤트 로그나 사후 추론이 아니다. 새 전투 이벤트나 난수는 생성하지 않는다.

## 모바일 사용성

선택 시 작은 하단 패널을 열고 `자세히 / 간단히`로 확장한다. `닫기`는 선택을 해제하여 전장을 돌려준다. 확장 패널은 세로 스크롤과 고정된 버튼을 제공하고 세로 높이의 45%, 작은 가로 화면에서는 48%까지만 사용한다. 한국어 단어 줄바꿈과 긴 문자열 넘침 처리를 적용했다. 지도 카메라·제어는 기존 Phaser 크기 변경/좌표 변환을 유지한다.

Chromium 터치 에뮬레이션에서 선택, 확장, 실제 손가락 스크롤, 닫기/재선택, 세로/가로, 팬/핀치, 일시정지/계속, 재시작 및 1×/2×/4× 진행을 확인했다. `v028-mobile.json`, `v028-inspector.png`에 증거를 저장한다. 실제 iPhone Safari, 배터리/발열 및 GPU 성능은 미검증이다. 자동 검사에서 한 병사 선택을 반복했으며 모든 지도 위치의 탭 성공을 증명하지는 않는다.

## 결정론 비교 및 테스트

`check-v028-parity.mjs`는 main 소스를 별도 디렉터리에서 불러와 기존/새 Battle을 같은 난수 시드와 0.05초 틱으로 완전 경기까지 실행한다. 새 버전에는 매 틱 이력 관측과 주기적인 검사/그래픽 호출을 추가한다. 결과·시간·난수 상태·좌표·상태·탄약·부상·제압·치료·임무·엄폐·거치·수류탄·분대 목표를 매 틱 해시한다. 최종 비교는 실제 경로/항법/진전/진단 데이터도 포함한다.

시드는 2001–2020, 지도는 legacy/expanded 각각 20개다. expanded의 layout=(seed−2001)%4, spawn=floor((seed−2001)/16)%3이며 수류탄은 expanded에서만 켠다. 같은 40개 비교의 초기 실행 80회와 강화된 최종 실행 80회를 보존한다. 별도로 기존 200개 legacy 시나리오를 0.1초 틱으로 재실행하여 보관된 `v025-after-A.json` 해시와 비교한다. 총 기록 실행 수는 360회이며 단위 테스트 내부 경기는 제외한다.

**최종 결과: 전체 테스트 220개 통과, 실패 0개. 기존 200개 레거시 해시 모두 일치. 최종 40쌍의 매 틱 해시·결과·시간 모두 동일하며 타임아웃 없음.** 초기/최종 비교 160회와 레거시 200회로 기록된 완전 실행은 360회다.

| 비교 조건 | 기존/새 버전 공통 P50 / P90 / P95 / 최대 시간(초) | 결과 |
|---|---|---|
| legacy (20쌍) | 70.85 / 162.10 / 196.85 / 196.85 | 모든 틱 해시 동일 |
| expanded (20쌍) | 92.60 / 159.95 / 186.40 / 186.40 | 모든 틱 해시 동일 |

동일 결과는 아래 기계 검증 자료에 기록한다. 전투 균형 개선이나 악화를 주장하지 않는다. 새로운 표시 모듈은 RNG를 호출하거나 병사/분대에 쓰지 않는다. 소스 동일성 검사 및 매 틱 비교가 서로 보완한다.

- `v028-parity.json`: 최종 40개 동일 조건 비교
- `v028-parity-initial.json`: 초기 40개 비교
- `v028-legacy.json`: 기존 200개 해시 검증 원자료
- `v028-validation.json`: 동일 모듈 SHA-256, 테스트 수 및 번역 리터럴 검사
- `v028-tests.txt`, `v028-build.txt`: 전체 테스트 및 빌드 로그

기존 216개 테스트와 새 4개 검사(권위 상태의 시각 표시/비변경, 한국어 대응/대체 문구, 이력 상한/중복 억제, 숨은 적 좌표 누출 방지)를 실행한다. Vite의 기존 Phaser 큰 청크 경고는 유지한다. Pages base와 배포 workflow는 변경하지 않는다.

## 실제 iPhone Safari 체크리스트 및 한계

1. 병사를 선택하고 기본/상세/닫기를 반복한다. 스크롤 중 전장이 움직이거나 글자가 겹치지 않는지 확인한다.
2. 세로/가로에서 카메라 초점, 팬/핀치, 원거리 병사 선택, 일시정지/재개/재시작, 앱 백그라운드 복귀를 확인한다.
3. 1×/2×/4×에서 실제 사격 플래시와 무기 방향, 관측선과 이동선, 완전 엄폐/피킹, 거치, 재장전, 제압/부상, 치료, 투척 및 사망을 비교한다.
4. 접촉 상실 후 표시가 마지막 확인 정보로 남는지, 숨은 적 이동을 따라가지 않는지, 부위별 부상과 치료 주기가 실제 상태와 맞는지 확인한다.
5. 장시간 관전 시 발열·프레임·메모리 반응을 확인한다. 이번 브라우저 검사는 장기 메모리 안정성이나 실기기 성능을 증명하지 않는다.

색 고리는 보조 수단이며 새로운 상세 스프라이트/장비 표현이 아니다. 화면 밖의 짧은 사건은 시각적으로 놓칠 수 있다. 번역되지 않은 동적 사유와 표본 사이 이력 누락은 남은 제한이다. 기존 v0.2.7의 의료·노출·대기·거치 기여도 관련 전술적 한계는 수정하지 않았다. 이번 업데이트는 이를 관찰하기 위한 것이며 AI 개선으로 주장하지 않는다.
