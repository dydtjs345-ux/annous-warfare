# Phase 2 — authored crouch integration

Branch `feat/phase2-authored-crouch`, based on approved build `420a0556b8bb4e66b4e94f18e916fa5b64b79776`.

Stage A source work is underway. Two actual external authored motions are retargeted onto the unchanged approved Tactical Suit: Quaternius UAL1 Standard RM `Crouch_Idle_Loop` → `P2_Quaternius_CrouchIdle_Rifle` (2.933333 s), and `Crouch_Fwd_Loop` → `P2_Quaternius_CrouchWalk_Rifle` (2 s). The body/rig/weapon are the existing CC BY 4.0 DanlyVostok model; new source motion is CC0. No new gait is authored from scratch.

`TacticalSuit_Phase2.glb` is a separate derivative. All four approved clip definitions and sampler bytes, original binary prefix, nodes, mesh/skin/material/texture data and weapon attachment nodes match the approved model exactly. Existing project crouch idle/walk were also retargeted as two explicitly labeled legacy comparison clips on the same actual external body. They are not new professional imports. All original files remain unchanged.

The Quaternius source crouch walk has approximately 15 cm of forefoot drift during a low support phase. Corrective contact phases are detected from the actual authored toe height; a constant stance anchor and continuous swing correction preserve source body motion while removing that slide. The first joint-only lock still left approximately 2.4 cm of deformed-boot movement. The final pass constrains a real boot-skin vertex, with leg IK and source foot/toe orientations. At 480 Hz after final GLB reimport, the maximum grounded contact-reference X/Y drift is about 0.0073 mm, minimum body Z is −0.057 mm and maximum wrist error is about 0.0014 mm. The tracked boot point stays within 2.7 mm of the floor; other sole vertices define actual lowest contact. These are geometric contact checks, not a force/centre-of-mass simulation.

The authored crouch walk retains about 16.08° pelvis rotation and 16.08° chest-relative-to-pelvis variation, versus 0° pelvis and about 1.39° chest-relative variation in the legacy comparison. The chest is relatively stable while the pelvis turns beneath it; no upper-body layer suppresses the source waist motion. The idle retains 3.33° pelvis and 5.06° chest-relative motion. Current rendered poses show a deep, forward-leaning crouch with controlled M16 grip. Full loop/comparison and transition preview validation continues before publication.

Standing/crouch entry and exit, dedicated crouched rifle aiming/firing and crouched reload are not claimed completed. No suitable exact clip for those actions has yet been verified in the free downloaded libraries. Prone/crawl, cover and weapon-handling stages are not advanced while Stage A is incomplete. Existing crawl remains an unapproved project candidate, not a professional imported substitute. Current reloads are preserved.

Source and technical artifacts are in `validation/`; licenses and exact attribution are in `licenses/`. `tools/retarget.py` reuses the established skeleton/weapon pipeline and writes only separate Phase 2 assets. `tools/contact_plan.py` derives contact corrections from actual source samples. `tools/merge.mjs` appends tracks to the approved asset without replacing it. No AI, squad-command system, map or live-game file is changed.
