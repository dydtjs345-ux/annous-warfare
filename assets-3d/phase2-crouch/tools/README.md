# Reproduction and continuation

Run from the repository root. Reuse Blender 4.3.2, Three.js 0.170, esbuild, Pillow, FFmpeg and a C compiler already available in this workspace. No engine or global package installation is required.

1. `blender -b --python assets-3d/phase2-crouch/tools/audit-source.py` inspects actual Quaternius source tracks and writes `source-motion.json`. `contact_plan.py` derives the reusable support/swing plan during retargeting. The source is the retained CC0 `assets-3d/open-asset-evaluation/source/UAL1_Standard_RM.glb`.
2. `blender -b --python assets-3d/phase2-crouch/tools/retarget.py` bakes the two external crouch loops; repeat with `P2_SOURCE=legacy` for the two labeled legacy comparison loops. This reuses the existing approved suit `.blend`, rig mapping and M16 grip-reference `.blend`; no new gait is procedurally invented. Outputs are separate intermediate GLBs ignored by Git.
3. `node assets-3d/phase2-crouch/tools/merge.mjs` appends only new motion buffers/tracks to the approved model. `verify-preservation.mjs` checks all 1,016 original file blobs, unchanged geometry/rig/attachments and the approved clip binary prefix.
4. `blender -b --python assets-3d/phase2-crouch/tools/validate-reimport.py` samples the final GLB at 480 Hz. `skin-bindings.mjs` derives live contact proxies from actual skin weights. `validate-controller.mjs` tests the actual Three.js state controller at eight headings and normal/half-speed sample steps. These checks do not claim browser GPU or physical iPhone execution.
5. Render actual final GLB playback with `P2_PROFILE=legacy|authored SU_ACTION=walk|idle SU_VIEW=side|iso SU_FRAMES=48 blender -b -t 2 --python assets-3d/phase2-crouch/tools/render-review.py`. Walk renders 48 frames / 2 seconds at 24 fps; idle renders at least 72 frames / 3 seconds to include its full native cycle. Render both `SU_VIEW=hands` and `hands-right` at `SU_TIME=.5 SU_FRAMES=1` for grip close-ups. `stitch-review.py` builds paired H.264/4-phase sheets from the actual render cache. No retiming or character substitution is applied.
6. Visually inspect contact sheets and frame sequences before publication. Set `AW_COMMIT` to the full pushed implementation SHA; run `build-preview.mjs` then `validate-preview.mjs`. Output defaults to `/workspace/phase2-crouch-dist`. Only add this folder as the new `/phase2-crouch/` route in the existing preview Site; all previous runtime files must hash-identically match the snapshot.

## Zen legacy FBX research, not an integrated asset

`zen-inventory.c` and `zen-pose-probe.c` reproduce the actual legacy FBX inventory and transform observation. They use **ufbx 0.23.1**, pinned commit `26a482ae66871d7de36eb722aa060bce95bce274` of https://github.com/ufbx/ufbx . Download `ufbx.h`, `ufbx.c` and `LICENSE` from that exact revision through ordinary permitted networking. Compile locally with `cc -O2 -I<ufbx-directory> <probe.c> <ufbx-directory>/ufbx.c -lm -o <output>` and pass the already downloaded pinned Zen FBXs as arguments. Reader license is retained in `../licenses/ufbx-LICENSE.txt`. No commercial converter or download gate bypass is involved.

The legacy takes parse, but the crouched pose's evaluated pelvis remains at its standing height while the ankles rise, and canonical axes are not resolved. Investigate FBX 6000 pre/post rotations, unit/root conventions and actual skin playback before generating a target clip. Do not interpret reader success as validated motion or relabel the one-handed revolver pose as rifle aiming. Keep these research files separate from the selected Quaternius clips.
